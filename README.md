# React CRUD – Quản lý người dùng

Ứng dụng CRUD đơn giản với React 18 (CDN + Babel), gồm các component `App`, `SearchForm`, `AddUser`, `ResultTable`.

- Tìm kiếm theo name/username
- Thêm, sửa (modal form), xóa người dùng
- Dữ liệu ban đầu từ https://jsonplaceholder.typicode.com/users

**Demo:** https://domaiviethoang.github.io/react-crud/
